# Local AI — مساعد ذكي محلي

نظام مساعد ذكي يعمل محلياً بالكامل على جهازك باستخدام Ollama و ChromaDB، مع دعم RAG (Retrieval-Augmented Generation) من الملفات النصية، وذاكرة طويلة المدى لحفظ المعلومات الشخصية.

## ✨ المميزات

- 💬 **محادثة ذكية** مع نماذج Llama عبر Ollama
- 📚 **RAG من الملفات** — رفع ملفات (TXT, PDF, DOCX, MD, XLSX, XLS) والبحث فيها
- 🧠 **ذاكرة طويلة المدى** — حفظ واسترجاع المعلومات الشخصية تلقائياً
- 🔒 **خصوصية كاملة** — كل البيانات محلية على جهازك
- 🌐 **واجهة ويب** — واجهة سهلة الاستخدام على http://localhost:5050

## 📋 المتطلبات

- Python 3.8 أو أحدث
- Ollama (مثبت ومشغل)
- حزمة Python المطلوبة (انظر التثبيت)

## 🚀 التثبيت

### 1. تثبيت Ollama

**Windows:**
1. حمّل Ollama من [ollama.com](https://ollama.com)
2. ثبّت البرنامج
3. افتح Terminal أو PowerShell واكتب:
   ```bash
   ollama serve
   ```
4. اترك التيرمينال مفتوح (الخدمة تعمل في الخلفية)

**macOS / Linux:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama serve
```

### 2. تنزيل الموديلات المطلوبة

في تيرمينال جديد (بينما ollama serve مفتوح):

```bash
ollama pull llama3.2:3b
ollama pull nomic-embed-text
```

- `llama3.2:3b` — موديل المحادثة
- `nomic-embed-text` — موديل التضمينات للـ RAG

### الموديلات المتاحة

يمكنك تنزيل أي موديل من القائمة أدناه حسب قدرات جهازك:

| الموديل | الحجم | RAM المطلوبة | الوصف | أمر التنزيل |
|---------|------|-------------|-------|------------|
| **llama3.2:1b** | ~1 GB | ~2-3 GB | خفيف وسريع للأجهزة الضعيفة | `ollama pull llama3.2:1b` |
| **llama3.2:3b** | ~2 GB | ~4-5 GB | متوسط (الافتراضي) — موازنة جيدة | `ollama pull llama3.2:3b` |
| **llama3.1:8b** | ~4.7 GB | ~6-8 GB | قوي للأجهزة المتوسطة | `ollama pull llama3.1:8b` |
| **llama3.1:70b** | ~40 GB | ~40-50 GB | أقوى موديل — يحتاج RAM كبيرة | `ollama pull llama3.1:70b` |
| **mistral:7b** | ~4.1 GB | ~5-6 GB | خيار قوي آخر | `ollama pull mistral:7b` |
| **qwen2.5:7b** | ~4.5 GB | ~5-6 GB | موديل صيني قوي | `ollama pull qwen2.5:7b` |
| **phi3:mini** | ~2.3 GB | ~3-4 GB | خفيف وسريع من Microsoft | `ollama pull phi3:mini` |
| **gemma2:9b** | ~5.5 GB | ~7-8 GB | موديل من Google | `ollama pull gemma2:9b` |

**ملاحظات:**
- `nomic-embed-text` ضروري لعمل RAG (البحث في الملفات)
- الموديلات الأكبر تعطي نتائج أفضل لكن تحتاج RAM أكبر
- يمكن تنزيل الموديلات من الواجهة في تبويب **الإعدادات**

**روابط الموديلات:**
- [Llama 3](https://ollama.com/library/llama3)
- [Mistral](https://ollama.com/library/mistral)
- [Qwen 2.5](https://ollama.com/library/qwen2.5)
- [Phi 3](https://ollama.com/library/phi3)
- [Gemma 2](https://ollama.com/library/gemma2)
- [Nomic Embed Text](https://ollama.com/library/nomic-embed-text)

## ⚙️ الإعدادات المتقدمة

### تحديد مسارات المجلدات

يمكنك تحديد مسارات مجلدات الملفات وقاعدة البيانات والموديلات من الواجهة:

1. اذهب لتبويب **الإعدادات**
2. تحت قسم **مسارات المجلدات**:
   - اضغط **اختر** بجانب "مجلد الملفات" لتحديد مسار حفظ الملفات
   - اضغط **اختر** بجانب "مجلد قاعدة البيانات" لتحديد مسار ChromaDB
   - اضغط **اختر** بجانب "مجلد الموديلات (Ollama)" لتحديد مسار موديلات Ollama
3. اضغط **حفظ المسارات** لحفظ التغييرات

**ملاحظة:** تغيير مسار الموديلات يعدل متغير البيئة `OLLAMA_MODELS`. قد تحتاج لإعادة تشغيل Ollama لتطبيق التغيير.

### الوصول الأونلاين عبر Ngrok

يمكنك الوصول للشات بوت من خارج البيت باستخدام Ngrok:

1. **الحصول على Ngrok Token:**
   - سجل في [ngrok.com](https://ngrok.com)
   - احصل على التوكن من Dashboard

2. **إعداد Ngrok من الواجهة:**
   - اذهب لتبويب **الإعدادات**
   - تحت قسم **الوصول الأونلاين (Ngrok)**:
     - أدخل **Ngrok Token** في الحقل المخصص
     - (اختياري) أدخل **Domain** لو عندك domain مدفوع
     - اضغط **حفظ الإعدادات**
     - اضغط **تشغيل** لبدء tunnel

3. **استخدام الرابط:**
   - سيظهر الرابط الأونلاين بعد التشغيل
   - انسخ الرابط واستخدمه من أي جهاز
   - نفس الملفات والذاكرة المحلية ستكون متاحة

**ملاحظات:**
- يجب أن يظل الكمبيوتر شغال و Ngrok مفعّل للوصول أونلاين
- Ngrok المجاني يغير الرابط كل مرة (استخدم Domain مدفوع لرابط ثابت)
- يمكنك إيقاف Ngrok بالضغط على زر **إيقاف**

### تثبيت pyngrok

```bash
pip install pyngrok
```

أو من requirements.txt:
```bash
pip install -r requirements.txt
```

## 📖 طريقة الاستخدام

### رفع الملفات والفهرسة

1. في الصفحة الرئيسية، اضغط على **"اختر ملفات"**
2. اختر الملفات المراد رفعها (TXT, PDF, DOCX, MD, XLSX, XLS)
3. اضغط **"فهرسة الملفات"** لمعالجتها وإضافتها للبحث
4. انتظر حتى تكتمل الفهرسة

### المحادثة مع الذاكرة والـ RAG

- اكتب سؤالك في مربع المحادثة
- اختر الموديل (افتراضي: `llama3.2:3b`)
- فعّل **"استخدام RAG"** لو عايز البحث في الملفات
- فعّل **"حفظ تلقائي"** عشان يحفظ المعلومات من الرسائل

### إدارة الذاكرة

- اذهب لصفحة **"الذاكرة"**
- يمكنك:
  - عرض كل الذاكرات المحفوظة
  - إضافة ذاكرة جديدة (مفتاح + قيمة)
  - تعديل ذاكرة موجودة
  - حذف ذاكرة
  - مسح كل الذاكرات

### حالة النظام

- اذهب لصفحة **"الحالة"**
- تعرض:
  - حالة Ollama (مشغّل أو لا)
  - الموديلات المتاحة
  - عدد الـ chunks المفهرسة

## 🛠️ API

### `/chat` (POST)

طلب محادثة مع الـ AI.

```json
{
  "messages": [
    {"role": "user", "content": "سؤالك هنا"}
  ],
  "model": "llama3.2:3b",
  "use_rag": true,
  "auto_memory": false
}
```

### `/memories` (GET)

عرض كل الذاكرات.

### `/memories/add` (POST)

إضافة ذاكرة جديدة.

```json
{
  "key": "اسم المفتاح",
  "value": "القيمة"
}
```

### `/memories/update` (POST)

تعديل ذاكرة.

```json
{
  "id": 1,
  "key": "مفتاح جديد",
  "value": "قيمة جديدة"
}
```

### `/memories/delete` (POST)

حذف ذاكرة.

```json
{
  "id": 1
}
```

### `/upload` (POST)

رفع ملفات.

### `/index_docs` (POST)

فهرسة الملفات المرفوعة.

### `/status` (GET)

حالة النظام.

## ⚙️ التخصيص

### تغيير الموديلات

في `rag.py`:

```python
EMBED_MODEL = "nomic-embed-text"  # موديل التضمينات
# في طلب chat:
model = "llama3.2:3b"  # موديل المحادثة
```

### تغيير المنفذ (Port)

في `app.py`:

```python
app.run(host="0.0.0.0", port=5050, debug=True, use_reloader=False)
```

غيّر `5050` للمنفذ المطلوب.
